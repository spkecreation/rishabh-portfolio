# Rishabh Raj — My Creative Desk

A responsive, buildless HTML/CSS/JavaScript portfolio based on the Figma Website Design homepage (Group 9, 8:884).

## Open
Open `dist/index.html` directly, or serve `dist` with any static web server. No package installation or build step is needed.

## Files
- `dist/index.html`: homepage
- `dist/styles.css`: layout, colors, typography and mobile styles
- `dist/script.js`: filters, image/video dialogs and mobile navigation
- `dist/case-study-*.html`: original case-study preview content
- `dist/assets/figma`: original exported design artwork
- `dist/assets/imported`: all 22 archive works, including original full-size stills

The two case studies are concept previews, as labeled on the source portfolio; no research metrics or outcomes have been invented. Contact links use rishabhraj.design@gmail.com. The résumé button shows an availability message until a résumé URL is supplied.

The homepage replaces the Figma sample brand with Rishabh's name and its illustrative project placeholders with the two projects on beyondrishabh.online. It adds the full creative archive below the play section.
